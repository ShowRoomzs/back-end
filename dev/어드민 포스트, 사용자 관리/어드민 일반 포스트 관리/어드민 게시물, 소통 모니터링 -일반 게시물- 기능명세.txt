## 54. 어드민 게시물 · 소통 모니터링 — 일반 게시물 — [v0.44 신설]

대상 화면: `ui-admin-11-general-posts.html` (title rev.1 / **h1 rev.3** · 2026.10.14 스튜디오 07 · 소비자 C18 정합), 상태 11종(목록 C1 · C9 / 상세 C2 · C3 · C5 · C6 · C8 · C10 / 모달 C4 · C7 / 원본 뷰어 C11). GNB **9 게시물 · 소통 모니터링 › 일반 게시물** — 배지 = **조치 필요 총건수**(신고 접수 + 이의 신청 심사 중). 상태 · 용어 · 처리 흐름은 **스튜디오 게시물((2) §24)과 1:1 대응** · 셸 · 테이블 · 모달 · 배지는 `ui-admin-05-change-requests` rev.6 재사용. **(2) §24-8 #16 「어드민 게시물 모니터링 화면 부재」의 일반 게시물 쪽을 해소**한다 — 공구 게시물 모니터링은 별도 화면이고 **아직 없다**(A-54).

**[rev.2 전면 수정 · rev.3 정합]** — 초안의 숨김 / 복원 2단 모델을 폐기하고 스튜디오 확정안(노출 중지 → 이의 신청 → 재게시 / 영구 삭제)에 맞췄다(명칭 숨김 → **노출 중지**). rev.3: ① 조치 사유를 **소비자 신고 사유 6종과 같은 축**으로 ② **신고자 마스킹** ③ 반려 후 **유예 7일 · 원본 내려받기** ④ **작성자 삭제 경로**(C10) ⑤ C4 안내의 「수정한 뒤 이의 신청」 삭제(중지 중 수정 불가) ⑥ 레일에 **작성자 조치 이력**(횟수만).

| 정의 | 스튜디오 정의 그대로((2) §24-6) — **작성자 기준 완전 삭제(복구 불가)** · 서버는 **비공개로 N개월 보관** 후 파기 · **운영자 콘솔(이 화면)에서만 조회** — 그래서 목록에 영구 삭제 행과 조회 전용 상세가 있다 |
| 삭제 유형 | **이의 신청 반려**(유예 7일 후) · **기한 내 미신청**(7일 경과) · **작성자 삭제**(중지 중 · 심사 전) |
| 유예 · 원본 내려받기 | 반려 후 7일 — 작성자만 원본을 내려받는다 · **내려받은 기록을 삭제 경위에 남긴다**(「내 사진을 돌려 달라」 문의의 답) |
| 보관 만료 | 「N개월 · 약관 근거 조항 필요 · 법률 자문 대기」 — 만료일이 지나면 파기되어 이 화면에서도 사라진다 · ⚠️ 보관 기산점(등록일 / 삭제일) 미정 → §55 B-14 |
| 지표 | 삭제 시점 동결 · 작성자 인사이트에서 제외 |

> ⚠️ **법률 · 약관 대기** — 이의 신청 기한 7일 · 심사 3영업일 · 유예 7일 · 비공개 보관 N개월은 **모두 가정값**이다. 기간은 운영정책에서 정하고(제재 이의신청은 약관상 최소 3영업일 — 인플 제22조②), **삭제 게시물 비공개 보관 근거 조항은 확정 약관에 없다**((2) §24-8 #1 · #2).
