| 카드 | 필드 · 규칙 |

| 사업자 정보 | 사업자: 사업자 여부 · 사업자 구분 · 상호 · 대표자명 · 사업자등록번호 · 사업장 주소 / **비사업자: 카드를 비우거나 없애지 않고 「비사업자 — 원천징수 대상 · 3.3% · 사업소득」**을 그 자리에 쓴다 — ⚠️ 사업자 구분 「일반과세자」는 스튜디오가 **수집하지 않는 값**(S-02 · A-07) · 상호 · 대표자명 · 사업장 주소의 **출처**(운영자가 등록증을 보고 입력하는지) 미정 → §55 B-10 |
| 정산 정보 | 은행 · 예금주(마스킹) · 계좌번호(마스킹 + **변경 이력 보조줄** 「변경 MM.DD HH:mm · 이전 {은행} ****NNNN」 — **지급 직전 계좌 변경은 사칭 신호**) · 지급 방식(사업자 「세금계산서 발행 · 리워드 + 부가세」 / 비사업자 「3.3% 원천징수 · 사업소득」) · 사업자 구분 변경 요청이 걸려 있으면 **「변경 요청 확인 중 ↗」**((1) §16-2a) — ⚠️ 라벨이 「지급 방식」 / 「원천징수 방식」으로 섞여 있다 → §55 D-31 |
| 운영 현황 | KPI 4 — 연결 브랜드 · 진행중 공구 · **정산 진행 중 리워드** · **조정 협의**(경고색은 조정 협의만 — 지급이 멈춘 유일한 수치) · 구 「누적 지급액 · 미지급액」(고정 지급비 기준)은 **모델 B와 맞지 않아 삭제**(A-06 해소) — 브랜드 상세와 축은 같고 돈의 방향이 반대 |
| **최근 정산** | 정산번호 · 공구 · 브랜드 · **단계(정산 관리와 같은 배지)** · 리워드(세전) · 지급(예정)일 · 조정 협의 행에 **합의 기한** + 「전액 보류」 · 행 클릭 → 정산 상세 · `[정산 관리에서 보기 ↗]` — 인플루언서 문의 1순위 「리워드 언제 · 얼마」에 이 화면에서 답한다 |

| 연결 브랜드 | 브랜드명 · 연결일 · 진행중 공구 · 연결 상태 · 행 클릭 → 브랜드 상세(§52) |

### 53-2. 마스킹 해제 — M4 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| 대상 | 본인확인 카드의 **이름 · 생년월일 · 휴대폰** — **CI/DI는 해제 대상 아님** · **계좌는 포함하지 않는다**(회원 관리의 목적은 신원 확인 · 송금은 다른 화면의 일) |
| 사유 | **정형 4종 필수** — CS 응대 · 정산 · 원천징수 확인 · 계약 · 분쟁 대응 · 수사기관 협조 · 상세 사유 · 기타 없음 |
| 범위 | **이 인플루언서 1건 · 이 세션 한정** — 다른 회원으로 이동하거나 **무조작 10분**이면 자동 재잠금 · `[지금 잠금]`으로 즉시 되돌림 |
| 표시(A1-u) | 실값 + 헤더 「해제됨 · 처리자 · 시각 · {남은 시간} 후 잠금」 · 생년월일에 만 나이 |
| 기록 | 열람 사실을 사유와 함께 **처리 이력에 즉시 기록** |
| 권한 | **최고관리자 한정** — 운영자 역할이면 `[해제]` 비활성 · ⚠️ A1-u 탑바가 「운영자」로 그려졌다(A-08 · A-41) → §55 C-8 |
