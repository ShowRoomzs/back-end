웹 3서피스는 로고가 단색 다크라 화면에 브랜드 레드가 등장하지 않는다. 따라서 --danger와 색이 충돌하지 않으며, 별도 딥레드 토큰이 필요 없다. 소비자 앱은 주 액션이 브랜드 레드라 이 조건이 성립하지 않는다 — 앱 디자인 시스템에서 별도 확정한다.

타이포그래피 — 서체

웹 3서피스(파트너센터·쇼룸 스튜디오·어드민) 공통 서체. 로고 워드마크(Fredoka)와는 별개 체계 — 로고는 브랜드 자산, 본문 서체는 제품 UI 전용.

항목내용
서체Pretendard — 무료 오픈소스(OFL 라이선스), 상업적 이용 무료
font-family'Pretendard', -apple-system, sans-serif
폴백 스택Pretendard 로딩 실패 시 -apple-system(맥 SF) → 시스템 기본 sans-serif 순으로 대체. 레이아웃은 깨지지 않고 서체만 달라짐
로딩 방식목업(HTML 시안)은 CDN(jsdelivr) 링크 방식 — 간편하지만 외부 의존. 프로덕션 핸드오프 시 npm install pretendard로 self-host 권장(로딩 안정성·속도, 라이선스 비용 없음)
두께(weight)현재 400(Regular) · 500(Medium) · 600(SemiBold) 3단만 사용 — 타이포 스케일과 매칭

필터 영역 (다중선택 · v1.2 신설)

탭과 구분 — 탭은 배타적 단일선택(카테고리가 서로 겹치지 않을 때), 필터 영역은 비배타적 다중선택(카테고리가 겹치거나 별개 축일 때)에 쓴다. 목록 툴바에 얹지 않고 별도 패널로 분리해 항상 펼쳐진 상태로 둔다 — 클릭 1번으로 즉시 필터링(펼치는 동작 없음).

규칙내용
그룹 구분그룹마다 별도 줄(row)로 분리 — 축이 다른 카테고리군을 세로로 쌓아 나열(예: 진열 상태 줄 · 공구 상태 줄). 그룹 내 항목은 서로 독립 — 완전히 같은 상태가 아니면 상위/하위로 합치지 않고 플랫하게 나열(위계 표현이 필요하면 항목명 자체에 표기)
다중선택그룹 내·그룹 간 모두 동시 선택 가능(AND 조건). 선택 시 체크박스가 인디고로 채워짐
초기화패널 우상단에 보더 있는 버튼(아이콘+"초기화")로 배치 — 텍스트 링크보다 클릭 대상이 명확. 항상 같은 위치에 고정(행이 늘어도 패널 최상단 우측)
사용 기준필터를 자주 바꿔가며 쓰는 목록 화면(운영자가 하루에도 여러 번 상태를 걸러보는 화면)에 적합. 필터를 가끔만 쓰는 화면은 트리거+팝오버 방식 등 다른 패턴을 검토
