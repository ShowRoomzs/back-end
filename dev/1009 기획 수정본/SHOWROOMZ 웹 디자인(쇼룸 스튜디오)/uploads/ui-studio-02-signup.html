Step2 · 활동 채널
항목내용근거
플랫폼 고정원본 4종 선택(IG/YT/TikTok/X) 폐기 → Instagram 고정(읽기전용)콘텐츠 의무 B안 = 인스타 고정 확정 · 타 플랫폼은 계약 이행 검증 불가
계정 아이디 필드신설 — 채널 주소에서 자동 추출, 수정 가능계약 이행 검증·게시물 확인의 식별 키
팔로워 수자기 신고 값(자동 크롤링 없음)운영자가 채널 주소로 수동 검증 후 승인/반려 — MVP 범위
쇼룸명신청서에서 제외 → 승인 후 온보딩(F5)으로 이관심사 통과 전 쇼룸명 선점 방지
계정 아이디 유효성인스타그램 아이디 작성 규칙과 동일 — 영문 소문자·숫자·마침표(.)·밑줄(_)만 허용, 최대 30자, 대문자는 자동 소문자 변환[신규제안 반영] 실제 인스타그램 아이디 형식과 어긋나면 채널 검증 자체가 불가능
팔로워 수 입력스피너(증감 화살표) 제거, -/+/e 키 입력·붙여넣기 스크립트로 원천 차단[신규제안 반영] 음수 팔로워 수는 무의미 — 온보딩 화면(§6)과 동일 원칙
Step3 · 약관 동의 — 필수 3 + 선택 1. 개인정보처리방침은 동의 체크 항목이 아니라 고지(보기) 문서로 분리(체크박스 없음). 필수 약관 미동의 시 에러 문구 없이 버튼 비활성만으로 표현(파트너센터 가입 §4-5 확정 원칙과 동일).
완료 — [결정 변경] 파트너센터 가입완료(`ui-partner-02-signup.html` E) 구조를 그대로 참고해 재작성. 단계 안내 리스트(1·2·3)를 정보 박스(info-box)로 교체하고, 반려·재신청 관련 부정적 안내 문구는 이 화면에서 전부 제거했습니다 — 반려·14일 재신청 안내는 로그인 화면(`ui-studio-01-login`)의 반려 모달에서만 다룹니다. 이 화면은 접수 완료라는 긍정적 상태만 전달합니다.
