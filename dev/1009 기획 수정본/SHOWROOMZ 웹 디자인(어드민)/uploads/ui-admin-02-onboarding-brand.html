항목변경
첨부 파일 형식 정정.pdf → .jpg. 회원가입은 jpg·jpeg·png만 허용하므로(기능요구사항 v0.7 §4-4 ⑩⑪⑱) 어드민에 PDF가 뜰 수 없다. 와이어 wf-admin-02의 PDF 표기를 그대로 옮긴 오류. 와이어도 동일 패치 필요

줌 · 드래그 제외마우스 이벤트·경계 처리·좌표 계산이 이 모달에서 가장 비싼 부분이라 MVP 제외. 대신 원본 열기(새 탭)로 브라우저 기본 확대를 쓴다. 화면 크기로 판독이 안 되는 스캔본은 어차피 반려 사유(첨부 서류 불량·누락)다. 추후 필요 시 라이브러리로 추가 — 지금 빼도 나중 비용이 늘지 않는다
