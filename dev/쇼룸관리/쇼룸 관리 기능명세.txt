## 22. 쇼룸 스튜디오 쇼룸 관리 — [v0.30 신설]

대상 화면: `ui-studio-05-showroom.html` (**rev.1**), 상태 7종(프로필 4 · 모달 1 · 현황 2). 셸·버튼·입력·배지·모달은 `ui-studio-04-connections.html` 규격을 재사용했다. 근거 와이어는 `wf-studio-05-쇼룸기본정보` **F1·F2**.

**성격 — 공개/비공개 분리가 이 화면의 설계 축이다.**

| 메뉴 | 성격 | 담는 정보 |
| --- | --- | --- |
| **8. 쇼룸 관리** (본 섹션) | **소비자 공개** | 쇼룸명 · 프로필 이미지 · 소개글 · 인스타그램 URL · 쇼룸 주소 · 연결코드 |
| 9. 기본정보 관리 (`ui-studio-06`, 후속) | **비공개** | 계정 · 사업자 정보 · 정산 계좌 · 활동 채널 |

구버전 목업 `studio-profile`이 프로필·활동채널·정산계좌를 한 화면에 섞어놓은 구조를 두 메뉴로 갈랐다. **"소비자가 보느냐"가 유일한 분리 기준**이다.

### 22-1. 쇼룸 프로필 — 공개 정보 — `FE`·`BE`

| 필드 | 필수 | 규칙 |
| --- | --- | --- |
| 프로필 이미지 | 선택 | **최소 160×160 · 정비율 · 최대 20MB · JPG·PNG·GIF** |
| 쇼룸명 | **필수** | **2~20자 · 특수문자 불가 · 중복 불가** · 소비자 노출 |
| 쇼룸 주소 | — | **자동 생성 · 수정 불가** · `복사` 제공 |
| 쇼룸 소개글 | 선택 | 50자 |
| 인스타그램 URL | 선택 | **소비자 노출** · `https://` 형식 검증 |

| 항목 | 규칙 |
| --- | --- |
| **앱 계정과 분리** | 쇼룸명·프로필 이미지를 **소비자 앱 계정과 공유하지 않는다.** 구버전의 "앱 계정 공유" 규칙은 **폐기** |
| **쇼룸 주소 불변** | 가입 시 쇼룸명 기준으로 자동 생성되며, 이후 **쇼룸명을 바꿔도 따라 바뀌지 않는다** |
| 인스타그램 URL의 출처 | 가입 온보딩의 채널 주소를 **기본값으로 가져오되 독립 수정 가능** |
| 저장 버튼 | **변경이 있을 때만 활성.** 유효하더라도 변경이 없으면 비활성 |

**앱 계정과 분리하는 이유** — 쇼룸은 **판매 채널의 간판**이고 앱 계정은 **개인 소비 계정**이다. 같은 값을 강제하면 어느 한쪽이 반드시 부적절해진다. 동일 인물이 두 이름을 갖게 되는 것은 **의도된 결과**다.

**쇼룸 주소를 고정하는 이유** — 링크가 바뀌면 인플루언서가 이미 인스타그램 프로필·스토리에 뿌려둔 링크가 전부 죽는다.

> **활동 채널과 별개 데이터** — 기본정보 관리(#9)의 활동 채널은 **계약 이행 확인용 비공개 데이터**다. 여기의 인스타그램 URL과 값이 같더라도 **같은 필드가 아니다.**
> 

### 22-2. 입력 검증 — 에러 문구 사용 범위 — `FE`

| 오류 유형 | 처리 |
| --- | --- |
| **필수 미입력** | **버튼 비활성만** — 에러 문구 없음 |
| **쇼룸명 중복** | 필드 보더 위험색 + **문구 1줄** |
| **URL 형식 오류** | 필드 보더 위험색 + **문구 1줄** |
| **파일 형식·용량 오류** | 업로드 영역에 **문구 1줄** |

| 항목 | 규칙 |
| --- | --- |
| 문구 위치 | 해당 필드 **바로 아래 1줄** |
| 복수 오류 | **동시 표시**한다(쇼룸명 중복 + URL 형식 오류가 함께 뜰 수 있다) |
| **업로드 실패 시** | **기존 이미지를 유지**하고 안내만 교체한다 — 아바타를 비우면 원래 이미지를 잃었다고 오해한다 |
| 중복 판정 범위 | 대소문자·공백·유사문자 처리 기준 **미정**(22-6 미결 4번) |

필수 미입력에 문구를 쓰지 않는 것은 §17·§19·§20과 동일한 원칙이다.

### 22-3. 연결코드 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| 발급 단위 | **쇼룸별 고정** |
| 용도 | 브랜드가 연결 요청 시 입력하면 **정확히 해당 쇼룸으로** 요청이 도착한다 |
| 액션 | `복사` · `재발급` |
| **재발급 확인 모달** | **필수** — 되돌릴 수 없는 액션 |
| 확정 버튼 색 | **위험색**(`btn-danger`) — 주 액션색(인디고) 규칙과 별개로 적용하는 **공식 예외** |
| 재발급 결과 | **이전 코드 즉시 무효.** 코드를 이미 전달한 브랜드는 새 코드를 다시 받아야 한다 |
| **기존 연결** | **유지된다** — 모달 본문에 함께 고지한다 |

**기존 연결이 유지되는 이유** — 코드는 **새 연결 요청용 열쇠**지 이미 성립한 관계의 근거가 아니다. 재발급으로 기존 브랜드 관계가 끊기면 인플루언서가 재발급 자체를 두려워하게 된다.

### 22-4. 쇼룸 현황 — 지표 — `FE`·`BE`

**와이어의 `팔로워` 탭을 폐기하고 `쇼룸 현황`으로 교체했다.** 팔로워 목록은 열람 전용·개인정보 미표시·개별 연락 불가라 **인플루언서가 그 화면에서 할 수 있는 행동이 없었다.** 화면의 목적을 **"쇼룸이라는 공개 채널의 반응 지표"**로 재정의했다.

| 카드 | 지표 |
| --- | --- |
| 팔로워 | 총 팔로워 / 기간 내 신규 / **직전 동일 기간 대비 증감률** |
| 쇼룸 도달 | 순방문 / 방문자 수 / **팔로우 전환율** |
| 팔로워 구성 | 연령대 · 성별 (집계 비율) |
| 지역 분포 | 시·도 |
| 팔로워 행동 | 평균 방문 횟수 / 재방문율 / 방문자 중 팔로워 비중 |
| 인기 콘텐츠 TOP 5 | 제목 · 게시일 · 노출 · 좋아요 |
| 유입 경로 | 인스타그램 링크 / 앱 검색 / 공구 게시물 / 직접 유입 |

**지표 정의**

| 지표 | 정의 |
| --- | --- |
| **순방문** | 방문 **횟수** — 같은 소비자의 재방문은 **30분 세션 기준 1회** |
| **방문자 수** | 중복 제거한 **사람 수** |
| **팔로우 전환율** | 기간 내 신규 팔로워 ÷ **방문자 수**(횟수가 아니라 사람 기준) |
| 증감률 | 직전 **동일 기간** 대비 |

| 항목 | 규칙 |
| --- | --- |
| 기간 선택 | 7 / 14 / 30 / 60 / 90일 / 6개월 / 1년 — **기본 30일** · **화면 전체에 적용** |
| 인기 콘텐츠 정렬 | 좋아요 많은 순(기본) / 노출 많은 순 — **최신순 제외**(순위표의 목적이 성과 비교라 시간순은 의미가 없다) |
| 팔로워 3번째 지표 | 게시물 총 개수가 아니라 **증감률.** 절대 수치만으로는 좋은지 나쁜지 판단할 수 없다. 게시물 개수는 콘텐츠 자산이라 **게시물(#5) 소관** |
| 전환율 분모 | **방문자 수.** 재방문이 많은 사람이 분모를 키우면 전환율이 실제보다 낮게 나온다 |

**의도적으로 두지 않는 것**

| 제외 항목 | 사유 |
| --- | --- |
| **개별 팔로워 목록** | 나열해도 할 수 있는 행동이 없다. 필요한 건 **누가 보는지에 대한 집계** |
| **언팔로우 수** | **어떤 형태로도 표시하지 않는다** |
| 인스타그램 링크 클릭 | **쇼룸 밖으로 나가는 행동**이라 쇼룸 도달 지표와 성격이 다르다 |
| 판매·정산 수치 | **판매 현황(#6) · 정산 관리(#7)** 소관 |
| 게시물 반응 표 | 인기 콘텐츠 TOP 5로 대체 |

> **개인 단위 정보는 어떤 카드에도 표시하지 않는다.** 이것이 쇼룸 현황 전체를 관통하는 규칙이다.
> 

### 22-5. 수집 한계 — 확정 전 전제 — `BE`

**시안이 명시한 전제이며, 확정 전에는 지표를 신뢰할 수 없다.**

| 항목 | 한계 | 필요한 결정 |
| --- | --- | --- |
| 연령대·성별 | 소셜 로그인(카카오) **동의자만** 집계 → 동의율이 낮으면 **"미확인" 비중**이 커진다 | 동의 항목 신청 여부 확인 |
| 지역 | 별도 수집 항목이 없어 **공구 배송지 시·도**로만 추정 → 구매 이력 없는 팔로워는 빠지므로 **표본 편향** | 별도 수집(가입 시 지역 선택) 도입 여부 |
| **표본 최소치** | 팔로워가 적을 때 구성 비율이 **개인을 특정**할 수 있다 | **일정 인원 미만 비율 비공개** 규칙 + 기준 인원 |
| 유입 경로 | 쇼룸 링크 소스 값(`?from=ig`)과 **앱 딥링크의 소스 보존 규칙**이 필요하다 → 없으면 대부분이 **"직접 유입"으로 뭉친다** | 링크 발급 규칙 확정 |

**빈 상태 처리** — 신규 인플루언서는 수치를 `0` 또는 `—`로 표시하고 **카드를 숨기지 않는다.** 카드가 사라지면 그 기능이 없는 줄 안다. 구성·지역·유입 경로는 각자의 빈 상태 문구를 갖는다.
