

## 31. 쇼룸 스튜디오 공구 관리 — [v0.34 신설]

대상 화면: `ui-studio-09-groupbuys.html` (**rev.3**), 상태 23종(목록 2 · 준비중 3 · 준비완료 1 · 진행중 5 · 종료 4 · 정산완료 1 · 중단 1 · 모달 6). 셸은 `ui-studio-04-connections`. GNB **#4 공구 관리**.

### 31-1. 파트너센터와 다른 점 — 7가지 — `FE`

| # | 차이 | 근거 |
| --- | --- | --- |
| 1 | **작성중 탭이 없다** | 발송 전 계약은 도착하지 않는다. 볼 수 있는 최초 상태는 **준비중** |
| 2 | **준비 게이트의 내 몫** | 파트너 B1의 `[확보 완료]` 자리가 **`[게시물 작성]`**이다. 게이트 3개 중 **가운데 하나만 내 차례** |
| 3 | **게시물은 작성 대상** | 파트너센터는 열람만 |
| 4 | **연장 응답 UI가 여기에만** | 파트너센터는 **발신 전용** |
| 5 | **금액의 방향이 반대** | 파트너센터 = **내는 돈** / 여기 = **받는 돈**. KPI 4번째가 **「내 리워드」** |
| 6 | **주문 처리 딥링크 없음** | 인플루언서는 주문을 처리하지 않는다. 종료 체크리스트에 버튼 없이 **남은 건수만** |
| 7 | **직권 중단에 소명 액션 없음** | 인플루언서 약관에 대응 조항이 없다 — §33-3 D-4 |

목록의 비고 열도 두지 않는다 — 요청·조치 여부는 **상세**에서 확인한다.

### 31-2. 공구 게시물 — 작성 규칙 — `FE`·`BE`

**일반 게시물(§24)과 합치지 않는다**

|  | 공구 게시물 | 일반 게시물(§24) |
| --- | --- | --- |
| 제목 | **필수** | 없음 |
| 상품·가격 | **계약 확정값 · 수정 불가** | — |
| 대가관계 표시 | **자동 삽입** | 없음 |
| 사진 | **없음** | 최대 20장 |
| 개수 | **공구 1건당 1개** | 제한 없음 |
| 승인 | **운영자 승인 필요** | 없음 |

**작성은 560px 모달** — 인플루언서가 채우는 값이 **제목·본문 둘뿐**이다(인플 제14조②).

| 항목 | 규칙 |
| --- | --- |
| 읽기 전용 | 상품 · 가격 · 기간 · 브랜드 — 모달 상단에 **잠금 표시** |
| **자동 삽입** | 대가관계 표시 · 판매자 정보 — **편집 필드를 두지 않는다**(표시광고법 근거 · 사람이 지울 수 있으면 안 되는 문구) |
| 사진 | **없다** — 공구 게시물의 이미지는 **상품 마스터**에서 온다 |
| 버튼 라벨 | **`[등록하고 검토 요청]`**이지 `[게시하기]`가 아니다 — **라벨이 결과를 잘못 약속하면 안 된다** |
| `[임시저장]` | 게시물 상태 **작성중**에 대응 · 저장해도 검토는 시작되지 않는다 |
| 수정 모달 | **같은 마크업**에 기존 값 · 헤더만 「공구 게시물 수정」 |
| 상한 | 제목 **40자** · 본문 **2,000자** — `[근거 대기]` |
| 필수 미입력 | **에러 문구 없이 버튼 비활성만** |

**등록 마감일을 역산해 알린다** — 시작일만 알려주면 **승인 SLA(영업일 3일)를 모르는 인플루언서가 시작 전날 등록해 공구를 못 여는 일**이 생긴다. B1 배너에 등록 마감일을 적고, 놓치면 **계약의 게시 완료 기한**까지 위험해진다는 연결을 함께 말한다.

### 31-3. 연장 응답 — 이 파일 고유 — `FE`

| ID | 화면 | 규칙 |
| --- | --- | --- |
| B6 | 요청 도착 · 내 응답 필요 | 요청 카드를 **최상단**에 · 배지는 **진행중 그대로**(요청은 상태가 아니다) · 응답 기한 = **현재 종료 시각** · **무응답 = 변경 없이 종결** |
| C1 | 수락 확인 | **불가역** · 새 종료일·총 기간을 요약으로 먼저 · **고정 지급비·리워드율은 늘어나지 않는다**를 함께 고지 · 확정 버튼 **주 액션** |
| C2 | 거절 확인 | **거절은 공구를 끝내지 않는다** — 원래 일정대로 계속됨을 먼저 말한다 · **중립 톤**(위험색 아님) · 사유 **선택** · 확정 버튼 **보조색** |

### 31-4. 중단 요청 — 양측 발신 — `FE`

| 상황 | 화면 | 규칙 |
| --- | --- | --- |
| **내가 발신** | C7 | **「남은 기간에 팔렸을 리워드는 받을 수 없다」**를 반드시 넣는다 — **중단을 요청하는 인플루언서가 잃는 것**이다 · 버튼은 `[중단 요청]`이지 `[중단]`이 아니다 |
| **브랜드가 발신** | B10 | 내 수락·거절 권한은 **없다**(연장과 다름) · 그래도 화면을 두는 이유는 **「검토 중에도 공구는 계속 팔린다」**를 알아야 하기 때문이다 — 이 고지가 없으면 요청 소식만 듣고 **게시물 홍보·문의 응대를 멈춰버린다** |

**인플루언서에게 요청권을 준 근거** — 상품 하자·배송 미이행·소비자 불만처럼 **중단이 필요한 사유를 먼저 발견하는 쪽이 인플루언서인 경우**가 많고, 소비자가 실제로 마주하는 창구가 **내 쇼룸**이다. 요청 권한이 없으면 문제를 알고도 계속 팔리는 것을 지켜봐야 한다. 약관 **제16조①**이 이를 이미 규정한다.

### 31-7. 종결 — `FE`

| ID | 상태 | 규칙 |
| --- | --- | --- |
| B8 | 정산완료 | 확정 실적 + 고정 지급비 · 판매 리워드 · 합계**까지만** · **공제 계산은 하지 않는다**(원천징수·실입금액은 정산 관리 소관) |
| B9 | 중단 | **위험색** — 내가 관여하지 않은 종결 · 핵심 고지 2가지: **고정 지급비는 회수되지 않고**, 중단 집행 이전 결제 완료 주문의 **리워드는 그대로 정산**되며 **잔여 기간 청구권은 소멸**(제16조④2) · 게시물은 **종료**로 바뀌어 쇼룸에서 즉시 내려간다 |

**종결 3종 모두** 콘텐츠 의무 카드는 남기되 **「계약이 성립하지 않아 효력 없음」**으로 표기하고, **「내가 받는 금액」 카드는 노출하지 않는다.**
