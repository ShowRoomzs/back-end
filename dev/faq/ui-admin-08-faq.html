[분류 체계] FAQ 카테고리 6종(배송 / 취소·교환·반품 / 주문·결제 / 서비스 / 계정 / 기타)은 1:1 문의 유형과 같은 축이다 — 문의 유형별 유입을 FAQ 보강으로 바로 연결하기 위함.
[와이어 수정] ⓐ 카테고리는 탭으로 노출한다 — 6종이라 탭 규격(4~5개)을 넘지만, FAQ 목록에는 상태 탭이 없어 탭 줄을 카테고리가 단독으로 쓴다. 건수 배지를 붙여 카테고리별 보유량을 목록 진입 즉시 파악한다. ⓑ 순서 조정은 행 핸들을 잡고 끌어 놓는 방식이다 — 핸들에 커서를 올리면 grab 커서로 바뀌고, 놓는 즉시 순서가 저장된다(별도 저장 버튼 없음). 이 시안에서는 실제로 끌어 옮겨진다 — 놓을 위치는 행 경계의 인디고 선으로 표시된다. ⓒ 목록 툴바의 정렬·순서 설명문은 컨트롤이 아니라 .stage에서 빼고 표시 건수 드롭다운(.sel-sm)으로 교체했다.
[필수 미입력] 에러 문구 없이 등록 버튼 비활성만으로 처리한다(C2).
[규격 정합] 테이블 본문 셀은 어드민 공통 규격대로 14px 16px · 행높이 50px(ui-admin-05 실측 13px과 1px 차이 — 디자인시스템 파일의 미결 항목). 상세 필드 행은 9px · 라벨 140px(.frow).
[주석 분리] 설계 근거는 이 박스와 각 상태의 .state-spec에만 둔다 — .stage 안에는 규칙 메모를 넣지 않았다.
