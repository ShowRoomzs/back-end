### 1-2. 공통 확인 방법

- **응답** — `jsonPath` 로 필드 존재 · 값 · null. 새 필드는 「없음」과 「null」을 구분하지 않는다.
- **칩 ↔ 목록 일치**(C1) — 칩의 `links[].query` 를 그대로 붙여 목록 API 를 불러, `totalElements` 가 링크 `count` 와 같은지 본다.
- **설정값** — `PostProperties` · `MemberProperties` 를 바꾼 테스트는 `finally` 에서 되돌린다.
- **시안 숫자** — P1 · D 묶음은 시안의 예시 숫자를 그대로 입력해 같은 값이 나오는지 본다.
