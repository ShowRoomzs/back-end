이 파일의 성격 — ui-admin-02-onboarding-brand.html(rev.1)의 셸·CSS·인터랙션 패턴을 그대로 재사용하고, 도메인 콘텐츠(필드·문구)만 인플루언서 심사 기준으로 교체한 것이다. 어드민 공통 규격(기능요구사항 §5-8)이 두 화면 모두에 동일 적용된다.

목록 컬럼브랜드의 브랜드명·담당자·연락처·사업자구분 → 계정 아이디·실명/연락처·팔로워 수로 교체(wf-admin-02 F2 기준). [신규수정] "활동명"은 제외 — 실제로 수집하는 정보가 아니라 목록·검색 전부에서 제거, 계정 아이디를 주요(굵게) 식별 컬럼으로 대체인플루언서는 채널·팔로워가 심사 판단의 핵심 재료. 활동명은 도메인모델(§1-2 활동 채널)에 없는 필드 — 목업 단계 임의 표기였음
반려 시 재신청 정책브랜드와 의도적으로 다름 — 브랜드는 계정 폐기 후 쿨다운 없이 즉시 재가입, 인플루언서는 반려일로부터 14일 경과해야 완전히 새 신청서로만 재신청 가능ui-studio-01-login.html(rev.1) §7-3에서 확정한 정책과 동일하게 맞춤. 두 화면이 같을 필요는 없다고 판단
반려 사유 선택지브랜드(사업자등록번호 불일치·통신판매업 신고 미완료·첨부 서류 불량 등 서류 중심) → 채널 실적 확인 불가·본인 인증 정보 불일치·허위 팔로워 의심으로 교체인플루언서 심사는 서류 대조가 아니라 채널·실적 검증이 핵심
승인 시 안내"로그인 후 온보딩(반품 수취 주소 등)" → "로그인 후 온보딩(쇼룸명·사업자 여부·정산계좌)"로 교체wf-admin-02 F3 인플루언서 상세의 규칙 노트 그대로 반영 — 쇼룸명은 신청서가 아닌 온보딩에서 입력(심사 통과 전 선점 방지)
계좌번호 마스킹 여부해당 없음 — 인플루언서 신청서에는 정산계좌 항목 자체가 없음(온보딩에서 별도 입력)브랜드의 "계좌번호 전체 노출" 규칙은 인플루언서 화면에 적용되지 않음
[법률 대기] 쟁점 F — 인플루언서가 사업자등록 없이 활동 시 통신판매업자로 오인될 리스크. 심사 단계에서 별도 안내 문구 필요 여부는 변호사 검토 후 반영(wf-admin-02 F3 원본 노트).
확인 필요 — 목록의 반려 행에서 실명·연락처·팔로워 수를 "파기됨"으로 표시했다(브랜드의 담당자·연락처 파기 표시와 동일 원칙 적용). 인플루언서도 브랜드와 같은 수준의 파기가 맞는지, 아니면 14일 후 재신청을 전제로 일부 보존해야 하는지는 [법률 대기] 쟁점과 함께 확인 필요.

[중요] 어드민 공통 디자인 시스템 v1.0(2026.05) 사용 금지 — 폐기 확정(2026.07). 본 시안은 SHOWROOMZ_웹_디자인시스템 v1.1 토큰만 사용한다. 브랜드 어드민 화면(ui-admin-02-onboarding-brand)과 완전히 동일한 셸·토큰이다.
포함하지 않은 상태 — 브랜드 화면에 있던 A2(검색 결과 없음)·D1(첨부 서류 미리보기)는 이 화면에서 제외했다. D1은 애초에 첨부 서류가 없어 불필요하고, A2는 브랜드와 동일 패턴이라 중복 제작하지 않았다 — 재구현 시 브랜드 화면의 해당 상태를 그대로 가져다 쓰면 된다. T(처리 완료 토스트)는 이번에 추가했다.
