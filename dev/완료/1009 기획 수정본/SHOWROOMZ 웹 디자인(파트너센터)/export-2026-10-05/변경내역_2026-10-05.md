이 폴더에는 오늘 수정한 9개 파일의 **최신본**이 들어 있다(11-claims 06b 기준 2차 수정까지 반영). 근거는 「거래 관리 결정 사항 1~15」(어드민 06a rev.4 · 06b 기준)이다.

## ui-partner-03-onboarding.html — 온보딩
- 「출고 소요일」 → **「발송 기한」**으로 바꿨다. 입력은 **공구 마감 후 [N 영업일] 이내** 한 줄(1~7 · 기본 3)이다.
- 도움말: 공구 마감 후 기준 · 최대 7영업일 · 상품 상세에 「공구 마감 후 N영업일 이내 발송」으로 자동 표시 · **영업일 = 주말·공휴일 제외, 연휴가 끼면 기한이 그만큼 늦어짐**
- 오류 문구를 「발송 기한을 입력해 주세요.」로 바꿨다.

## ui-partner-06-basic-info.html — 기본정보 관리
- 배송·반품 정책의 「출고 소요일」 → **「발송 기한」**(공구 마감 후 [N 영업일] 이내)으로 바꿨다. 단위 글자가 겹치던 배치도 고쳤다.
- 도움말을 온보딩과 같게 맞췄다(주말·공휴일 제외 포함).
- `.rule` 근거를 다시 썼다: 발송 기한 = 마감 + N영업일 · 전자상거래법 제15조① 공급 시기 약정 근거 · 상품 상세 자동 고지 · 값을 바꾸면 이후 접수 주문에만 적용 · `[근거 대기]` 상한 7 / 약정 인정 요건

## ui-partner-10d-orders-cancel.html — 취소 요청·취소
- **A2f 목록**: 「1영업일(주말·공휴일 제외) 안에 처리 · 넘기면 자동 승인 · PG 즉시 환불 · 요청이 걸린 **하위주문 전체** 송장 등록 불가」 안내를 넣었다. 「경과」 열 → **「응답 기한」**(남은 시간)
- **C11 상세**: 요청하지 않은 항목은 **「발송 보류 · 취소 요청 처리 대기」**로 표시한다.
- **E6 승인**: 환불은 PG가 자동 처리한다.
- **E7 거부**: 거부 사유를 **드롭다운**(이미 포장·출고 완료 / 택배사 집화 완료 / 주문 제작·맞춤 상품 / 기타 + 상세 입력)으로 바꿨다. 「환불은 일어나지 않습니다」 문구를 넣었다.
- `.rule`: [rev.6 · 응답 기한 1영업일 · 자동 승인] 단락을 신설했다. 하위주문 단위로 잠그는 근거와 영업일 기준도 적었다.

### 10a~10e 공통 `.rule`
- 환불 실행 주체: 「운영자가 집행」 → **「환불은 PG가 자동으로 처리합니다」**(결정 1)
- 집화 확인 필요 = **24시간**, 72시간 「집화 지연」 폐기(결정 6)
- 발송 기한 = **공구 마감 시각 + 브랜드가 정한 N영업일**(기본 3 · 최대 7). 진행 중 결제 건은 마감 전까지 기한이 없다(결정 3 + B안). 목록 헤더 툴팁도 맞췄다.
- 발주서 다운로드 = 준비 시작(선택 없음)
- [구매확정 ≠ 정산 완료]: 확정 후 하자는 **운영자가 클레임을 대신 개설**하고, 브랜드는 검수만 한다(결정 2).
- 택배사 목록 = **추적 연동 업체 목록 하나를 출고·회수 공통**으로 사용(결정 5)

## ui-partner-11-claims.html — 반품·교환 관리
- **용어 통일**: 검수 단계의 「거절」(검수 거절 · 거절 보류 · 거절 제출 · 거절 반송 · 거절 종결 등)을 모두 **「반려」**로 바꿨다. 「거절」은 10d 취소 요청 거부에만 쓴다. 「신청 단계 거절」은 검수 전 거절이 없다는 뜻이라 그대로 뒀다.
- **규칙 박스**: [환불 집행은 운영자 전용] → **[브랜드는 검수 판정까지 · 통과 즉시 PG 자동 환불]**
- **M1 검수 통과 확인 모달 신설**: 「검수를 통과할까요?」 · 되돌릴 수 없음 · 통과 즉시 PG 자동 환불 · 환불 예정 금액 표시
- **B1r 검수 반려 폼 6항목**: 사유 · 법적 근거(전자상거래법 제17조② 각 호) · 범위(전체/일부 + 수량) · 귀책(변경 없음/브랜드 귀책 인정) · 증빙 사진 · 소비자 메시지. 소비자 C10-5와 1:1로 맞췄다.
- **반려 보류(A6)**: 「폐기할 수 있다」 서술을 모두 지웠다. 고지 횟수 · 보관 기한만 표시한다(약관 반영 전 폐기 없음).
- **A5 재발송 탭**: 「재발송비」 열(결제됨 / 결제 대기)을 추가하고 「재발송비는 브랜드 수취액에 더해집니다 · 리워드 기준에는 포함되지 않음」 안내를 넣었다(결정 14).
- **상세 모달(B1 · B1r · B2)**: 검수 판정 박스 맨 위에 **구매확정 타이머 「정지 · 남은 4일」**을 넣었다. 요청 시점부터 멈추고, 철회되면 남은 일수부터 재개된다.
- **운영자 개설 클레임**: 목록 행과 B1 상세 사유 줄에 **「운영자 개설 · 구매확정 후 하자 · 증빙 2장」**을 표시했다.
- **E1 엑셀 다운로드**: 회수 대기 → **재발송 탭**으로 옮겼다(회수는 소비자가 직접 발송).
- **[미정] ④ 영업일 기준** → 「주말·공휴일 제외」로 해소했다(결정 15).
- 관리 열 폭을 140px 이상으로 넓혔다(버튼이 오른쪽에 붙던 문제).

## ui-partner-13-settlement.html — 정산 관리
- 정산 금액 분해에 **「재발송비 +0원」** 줄을 넣었다. 브랜드 수취액에만 더해지고 리워드 기준 판매금액에는 포함하지 않는다는 주석을 달았다. 이 공구는 재발송이 없어 0원이다(결정 14).
