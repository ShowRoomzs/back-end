## C10 주문 내역
- **할 일 표시**: 고객이 해야 할 일이 남은 반품·교환은 상태 아래 로즈 한 줄 + 기한
  - 「회수 송장 등록 필요 · 10.11까지」 / 「재발송 배송비 결제 필요 · 10.23까지」
- 송장 기한 초과 자동 취소: 상세 화면 없음, 알림만 · 원래 상태(배송완료)로 복귀
- **취소 요청 완료 화면**: 「취소 요청이 처리될 때까지 이 주문의 상품은 발송되지 않아요」 추가 (결정 13)
- **취소 상세 「확인 중」**: 「브랜드가 1영업일(주말·공휴일 제외) 안에 확인하지 않으면 자동으로 취소돼요」 (결정 8 · 15)
- **취소 완료**: 「쿠폰·적립금 즉시 반환」 문구 삭제 (결제에 쿠폰·적립금 없음)

## C10-1 주문 상세
- **결제완료(1a)**: 배송지 제목 옆 [배송지 변경] → C13-2 배송지 선택. 상품준비중 이후는 「주문 시점 정보」로 고정
- **상품준비중(1b)**: [상태] 전환 추가 — 기본 / 일부 취소 요청
  - 일부 취소 요청: 요청한 상품은 「취소 요청 · 브랜드 확인 중」 + [취소 상세], 나머지 상품은 버튼 없이 「취소 요청이 처리될 때까지 이 주문의 상품은 발송되지 않아요」 (결정 13 · 하위주문 단위 송장 잠금)
- **반품 진행 중 행**: 할 일 로즈 한 줄 표시(목록과 동일)
- **구매확정**: 버튼 [1:1 문의] + 안내 「상품에 하자가 있으면 1:1 문의로 접수해 주세요 — 확인 후 반품을 열어 드려요」 (결정 2 · 셀프 반품 없음)

## C10-2 배송 조회
- 1a에 [배송 종류] 전환: 일반 주문 / 교환 상품 발송 / 반려 상품 재발송
  - 일반 외: 주문 날짜 앞 회색 라벨 + 상품 아래 안내 한 줄
  - 반려 상품: 「반려된 상품은 반품 · 교환할 수 없어요」

## C10-3 반품 · 교환 요청
- **반품 사유 「기타 (직접 입력)」 추가**: 소비자 귀책 기본 · 상세 입력 필수 · 배송비 3,000원 차감 · 검수에서 브랜드 귀책 인정 가능 (결정 10)
- **교환 옵션 시트**: 받은 옵션과 **가격이 같은 옵션만** 노출. 다른 가격은 반품 후 재주문 (결정 11)
- **택배사 목록**: 추적 연동 업체 기준 10개로 정리, 자유 입력 없음 (결정 5)
  - CJ대한통운 · 우체국택배 · 한진택배 · 롯데택배 · 로젠택배 · 경동택배 · 대신택배 · 일양로지스 · CU 편의점택배 · GS25 편의점택배
  - ⚠️ 잠정 목록 — 실제 연동 목록 확정 시 교체 필요
- 교환 받을 곳 [배송지 변경] → C13-2 배송지 선택 페이지(시트 아님)

## C10-4 회수 조회 (신규)
- 고객 → 브랜드 방향 조회. 택배 단계 + 브랜드 단계(입고·검수 중 → 검수 완료)
- 조회되지 않음 상태: 송장 등록 후 **24시간** 미조회 시 · [송장 수정] → C10-5 송장 등록 화면 재사용 (결정 6)
- 택배사는 연동 목록에서만 선택 — 자유 입력 없음 (결정 5)

## C10-5 반품 · 교환 상세
- **반품 상세(1b) [상태] 추가**: 반려 · 재발송 / 반려 · 수령 완료
  - 결제 후 반려 사유는 이력으로 유지, 결제 자리에 「결제 완료」 확인 박스
  - 재발송 중 [배송 조회] → C10-2
- **검수 반려 보관 문구**: 「보관 기한 10.23 · 이후 처리는 고객센터로 안내드려요」 — 약관 반영 전까지 폐기 문구 없음 (결정 12)
- **구매확정 표기**: 신청 정보에 「구매확정」 줄 추가 (결정 7)
  - 진행 중: 「반품 처리 중 · 구매확정 일시 정지」 / 「교환 처리 중 · 구매확정 일시 정지」
  - 교환 완료: 「교환 완료일부터 7일 새로 시작」
- **교환 상세(1c)**: 새 옵션 표기를 같은 가격 옵션 기준으로 변경 · [배송지 변경] → C13-2
- 택배사 목록 C10-3과 동일하게 정리
- 「쿠폰·적립금 즉시 반환」 문구 삭제
- 버튼 연결 노트 정리: [회수 조회] → C10-4 · 재발송 [배송 조회] → C10-2 · [1:1 문의하기] → C12

## C13 배송지 관리
- **C13-2 배송지 선택 (신규)**
  - 진입: C10-1 결제완료 [배송지 변경] · C10-3 교환 요청 · C10-5 교환 상세
  - 단일 선택(로즈 라디오 + 틴트) · 현재 주소가 기본 선택 · 다른 주소를 골라야 [이 배송지로 변경] 활성
