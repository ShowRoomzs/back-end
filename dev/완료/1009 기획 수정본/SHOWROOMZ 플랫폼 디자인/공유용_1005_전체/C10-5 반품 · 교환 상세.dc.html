구매확정 일시 정지 — 반품·교환을 요청하면 해당 항목의 구매확정 타이머가 멈추므로, 예정일 대신 "반품 처리 중 · 구매확정 일시 정지"를 신청 정보에 적습니다. 철회·자동 취소되면 남은 일수부터 다시 흐르고, 교환이 완료되면 7일이 새로 시작됩니다. 검수 반려 보관은 약관 반영 전까지 폐기 문구 없이 "보관 기한 MM.DD · 이후 처리는 고객센터로 안내"로만 씁니다. 택배사 목록은 추적 연동 업체 목록과 같고 자유 입력은 없습니다.

직접 발송 흐름에 맞춘 반품 상세 — 구성은 참고 화면 그대로입니다: 신청 일시 + 주문번호 + [주문 상세] → 반품 상품 N개 → 유의 박스 → 상품 위 상태 → 상품 아래 버튼 → 반품 신청 정보 → 환불 정보 → 안내. 위 [상태]로 세 구간을 전환합니다.

상태별 차이 — 송장 입력 필요: 상태 줄 "반품 요청 · 회수 송장 입력 필요"(뒷부분 로즈 — 사용자가 해야 할 일), 회수 송장 칸에 등록 기한, 버튼 [요청 철회] [회수 송장 등록]. 송장 등록은 이 화면 안의 회수 송장 등록 화면으로 갑니다. 철회는 확인 모달로 처리합니다(상품 하나 단위라 별도 페이지가 필요 없음). 회수중: 송장이 붙어 추적 중 — 이미 보냈으므로 철회 버튼이 사라지고 [회수 조회]만 남습니다. 반품 완료: 유의 박스가 사라지고 완료 일시가 채워지며 금액 라벨이 "환불 금액"으로 바뀝니다. 할 일이 끝난 상태라 버튼은 두지 않습니다.

검수 반려 — 반려는 상품이 브랜드에 도착한 뒤 검수 단계에서만 일어납니다(요청 단계 반려 없음). 상태 줄 "반품 반려 · 재발송 배송비 결제 필요"(로즈) 아래에 반려 사유 블록 — 사유 · 법적 근거 · 브랜드 증빙 사진 · 브랜드 메시지 — 을 두고, 이어서 상품 다시 받기(재발송 배송비 3,000원 · 결제 기한 14일 · 결제 수단은 C9와 같은 신용·체크카드 / 간편결제)를 붙였습니다. 하단 고정 CTA는 "3,000원 결제하고 다시 받기"이고, 상품 아래 버튼은 이의 제기용 [1:1 문의하기] 하나입니다. 환불 금액은 0원(회색) — 환불이 없어 차감할 곳이 없으므로 결제가 필요한 유일한 경우입니다. 일부 반려(여러 상품 중 일부만 반려)는 승인된 상품의 환불액이 있으므로 거기서 재발송 배송비를 차감하고 결제 수단·CTA를 두지 않습니다(환불 정보에 승인 상품 금액 · 재발송비 차감 줄 추가). 미결제 시 — 기한(14일)이 지나면 2회 이상 다시 고지하고, 최종 고지일로부터 3개월 보관 후 반환 요청이 없으면 폐기할 수 있다고 안내합니다(올리브영 정책 참고, 약관 반영 필요). 결제 후에는 [반려 · 재발송](버튼 [배송 조회] → C10-2 "반려 상품 재발송") → [반려 · 수령 완료](버튼 없음, 종결)로 이어집니다 — 반려 사유 블록은 이력으로 남고 결제 블록 자리에 "결제 완료" 확인 박스가 들어갑니다.

버튼 연결 — [회수 송장 등록] → 이 화면 안의 송장 등록 · [회수 조회] → C10-4 회수 조회(고객 → 브랜드, 검수 단계 포함) · 반려 후 재발송 [배송 조회] → C10-2 배송 조회("반려 상품 재발송" 라벨) · [1:1 문의하기] → C12.
