## 12 정산 관리 (rev.3 · 11개 상태)
**상태 · 흐름**
- 상태 4종 — 정산 확인 중 · 조정 협의 · 지급 예정(**중립**) · 지급 완료
- D1 정산 확인 중 — 「09.24 23:59까지 … 요청이 없으면 다음 날 자동 확정돼요」
- C1 정산 조정 요청 — 입력은 **금액 + 사유**(근거 첨부 삭제) · 원천징수 · 실지급 자동 계산
- D2 조정 협의 — 조정 내역 블록 + [이슈 스레드 열기]
- D3 차감 반영 — 차감 행 + 대상 주문 · 원 공구 · 사유 블록 · 차감 후 금액으로 원천징수
- 지급 예정일 = **자동 확정일 + 3영업일**(사업자는 발행 확인일 + 3영업일)

**지급 구조**
- 지급자 = **SHOWROOMZ · PG 분배**
- 비사업자 증빙 — 원천징수영수증 · 발행 SHOWROOMZ · [다운로드](지급 완료 시 활성)
- 목록 상단 **[연간 지급 내역]**(연도 선택)
- 사업자 — 공급가 = 리워드 · 부가세 10% 별도 → 실지급 602,800원
- 사업자 세금계산서 카드 4상태 — **D5 발행 필요 · D5a 확인 중 · D5b 반려 · D5c 확인 완료**

**3자 분배**
- 브랜드 = 확정 거래액 − PG 3% − 리워드 − 리워드 부가세(D4 · D5 4,712,800 / D2 9,193,276 / D3 552,230 / D1 4,926,600)
- 플랫폼 — 비사업자 = 리워드 부가세(신고 · 납부) / 사업자 = 0원
- 같은 회차는 브랜드 · 인플루언서 지급일 동일

**삭제**
- 고정 지급비 블록 · 「공구 총 수령액」 합산
- 주민번호 미등록 화면(D3a)
- 차감분 원천징수 [자문대기-세무] 태그
