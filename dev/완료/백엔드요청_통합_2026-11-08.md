## 6. 기획 결정이 필요한 것 (백엔드 · 기획 같이)

정해지면 대부분 설정값이나 작은 수정으로 끝난다. 결정 전에는 서버 현재 동작대로 둔다.

**정책값 미정(설정만 넣으면 됨)** — 화면에는 「[정책값 미정]」이 보인다.
- 고정 지급비 지급 영업일 `fixedFeePaymentBusinessDays`(파 · 스)
- 정지 소명 검토 영업일 `sanctionAppealReviewBusinessDays`(스, `application.yml:298` 주석 처리)
- 인플루언서 계좌 변경 운영자 확인 영업일 `creatorAccountReviewBusinessDays`(스)
- 정지 사전 통지 N영업일(어, 설정 키 자체가 없다)
- 플랫폼 수수료 표기: 계약 상세는 상수 2%, 실제 정산은 베타 0%. 무엇을 보일지 정하고 `policy-values`나 공구 상세로 내려 달라(파 · 스 · 어)

**소비자 앱**
- 취소 요청 부분 수량 — 서버는 항목 단위 전량만 받는다(`UserCancelDto.java:28`), 시안은 수량 선택
- 1:1 문의 [이어서 문의하기]와 기간 — 이어쓰기 API 없음
- 교환 귀책 변경 환급 화면을 둘지 · 정지 배너 「{날짜}까지」를 시안에 넣을지

**파트너센터 · 스튜디오 공통**
- 정지 중 탈퇴: 서버 기본값은 허용(`allow-withdrawal-while-suspended: true`), 스튜디오 시안은 차단
