### 32-2. 오픈 승인 — 체크리스트를 두지 않는다 — `FE`

**MVP에 금액·기간 임계값이 없다.** 없는 기준으로 만든 판정표는 **있지도 않은 규칙이 있는 것처럼** 보이게 한다.

**검토는 대조 작업이다**

| 대조 대상 | 확인 |
| --- | --- |
| 게시물 원문 | **표시광고법 위반** |
| 상품 항목 ↔ 상품 마스터 | **계약과 다른 상품·가격** |
| 자동 삽입 문구 | **대가관계 표시 훼손** |

| 항목 | 규칙 |
| --- | --- |
| 게시물 원문 | **전체를 그대로** 노출한다(제목·본문·담긴 상품 · 사진 없음) |
| **상품 칩 = 상품 상세 링크** | 심사 기준이 「계약과 다른 상품·가격」이라 **마스터 값을 바로 대조**할 수 있어야 한다. 종결 화면의 칩도 같은 링크를 유지한다 |
| 버튼 위치 | 승인·반려를 **게이트 줄과 우측 레일 두 곳**에 둔다 — 스크롤 위치에 따라 손이 닿는 곳이 다르다 |
| SLA 표기 | 기한 **D-2**와 **시작일**을 함께 적어 **승인이 늦으면 공구가 열리지 않는다**는 연결을 말한다 |
| **지급 문구 없음** | 오픈 승인의 결과는 **공구가 열리는 것 하나**다(§29-9) |

**반려 사유 7종** — 표시광고법 3 · 계약 불일치 2 · 대가관계 1 · 기타. **심사 기준과 같은 축**이라 반려 사유별 통계가 바로 나온다.

**M1 반려 모달** — **설명이 필수**다. 고칠 문장을 지목하지 않으면 **재등록이 반복된다.** 경고문에 **준비중 정지 · 시작일 기한** 2개를 적는다.

### 32-6. 정산 — `FE`·`BE`

**정산 상태머신은 어드민에만 있다** — 정산대기 → 운영자 확인 → 이체완료. 양측에는 **「받았는지 아직인지」만** 의미가 있고 중간 단계를 노출하면 **운영자 내부 절차가 새어 나간다.**

| 화면 | 상황 | 남은 선행 조건 |
| --- | --- | --- |
| **B5** | 정산 보류 · 이행 미합의 | **둘** — 미종결 주문 + 이행 미합의 |
| **B5a** | 이행 합의 완료 · 보류 해제 | **하나** — 미종결 주문 |
| **B5b** | 양측 이행 확인 완료 · 정상 | **하나** — 미종결 주문 |

| 항목 | 규칙 |
| --- | --- |
| **사유가 둘이면 카드도 둘** | 종료 화면이 답할 질문은 **「왜 아직 정산이 안 되나」 하나**이고, **사유가 하나만 보이면 나머지를 찾아 헤맨다** |
| 이행 확인 카드 위치 | **좌측 맨 위** — 미이행 제출 사유가 **읽을 글**이라 320px 레일에 들어가지 않고, 정산이 멈춘 이유를 **가장 먼저** 답해야 한다 |
| **조회 + 스레드 개설까지만** | 합의는 **게시물·소통 모니터링**, 보류 해제는 **정산 관리** 소관이다. 여기에 처리 버튼을 두면 **같은 건을 세 화면이 각자 처리**하는 셈이 된다 — 두 버튼 모두 **보조 톤**이고 하나는 **딥링크** |
| B5a 합의 결과 기록 | **미이행이 무엇으로 해소됐는지가 정산 금액의 근거**가 되고 **나중에 되짚는 유일한 기록**이다. 단 **회사의 중재 의견에 금액 조정은 포함되지 않으므로**(제20조④) 여기 남는 것은 **당사자가 합의한 결과**이지 운영자의 판정이 아니다 |
| B5b 무응답 표기 | 한쪽이 **무응답 → 자동 이행**이면 **그 사실을 반드시 적는다** — 실제로 확인한 것과 기한이 지나 자동 처리된 것은 뜻이 다르고, **「확인한 적 없다」는 분쟁이 나면 이 한 줄이 근거**다 |
| B5b 이슈 버튼 | **남긴다** — 합의용이 아니라 **정산과 무관한 이견**을 여는 창구이고 이행 확인이 끝난 뒤에도 열 수 있다 |
| 미종결 건수 | **우측 레일**로 올린다(정산 실행의 판단 근거) · 경로별 내역은 판매 관리 소관 |
| **정산 예정 금액** | 리워드를 **확정 대기**로 두고 **잠정 금액을 쓰지 않는다** — 미종결 결론에 따라 바뀐다 |
| **지연 감시** | 종료 +30일 · **기한 도달 전에는 정보 톤**이고 경고 톤은 **실제로 30일을 넘긴 뒤에만** 쓴다 — 아직 발생하지 않은 조건을 조치 필요로 표시하지 않는다 |
| **독촉 버튼** | **두지 않는다** — 독촉은 **알림·CS 경로**의 일이고, 버튼이 있으면 **운영자가 눌러 놓고 처리했다고 여긴다** |

| **C-3** | 파트너 약관 **제16·17조 번호 중복** — 각 2개씩 존재해 이후 조문이 +2 밀린다. 본 문서가 인용한 조 번호는 **정정 후 재대조** 필요 |

### 33-3. 약관 근거 부재 — `[약관보완-2차질의]`

| # | 항목 |
| --- | --- |
| **D-1** | **이행 확인 무응답 = 이행 간주의 근거 없음** — 인플 제20조⑦은 **이슈 스레드 내부**의 답변 무응답만 다룬다. 이행 확인 단계의 기한·무응답 처리 규정이 없는데 화면은 기한 경과 시 자동 진행으로 그려져 있다. **인플루언서에게 불리한 간주 조항**이라 근거가 필요하다 |
| **D-2** | **정산 보류의 출구 없음** — 제20조⑤가 「한쪽이라도 반대하면 보류 계속 유지」로 두어 **무한 보류**가 가능하다. §33-1 14번의 답이 약관에 없다 |
| **D-3** | **정산 보류 사유의 범위** — 제20조는 **이행 미합의만** 보류로 규정하는데 어드민 B5는 **미종결 주문**과 함께 「정산이 멈춘 사유」로 묶는다. 미종결 주문은 보류가 아니라 **정산 선행 조건 미충족**이라 성격이 다르다 (1차 답변 #13 「취지 불명」 미답 항목) |
| **D-4** | **인플루언서 약관에 직권 중단 소명 조항 부재** — 제17조②④가 **브랜드에게만** 통지·소명을 보장한다. 스튜디오 B13에 소명 액션을 두지 못한 이유이며, **1호 법령 위반은 대개 게시물 문구**인데 정작 당사자가 소명할 자리가 없다 |
| **D-5** | **고정 지급비 회수** — 제16조④1 「회수되지 아니합니다」와 변호사 1차 답변 8번의 **인플루언서 귀책 시 환불 권고**가 어긋난다. 직접지급형에서는 플랫폼에 집행 수단이 없으므로 **브랜드의 직접 청구권** 형태여야 한다 |
