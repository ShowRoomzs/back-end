ui-studio-05-showroom — 쇼룸 스튜디오 쇼룸 관리

근거: wf-studio-05-쇼룸기본정보 F1·F2(쇼룸 프로필 · 팔로워) · ui-studio-04-connections.html(메인 셸 · 컴포넌트 재사용) · SHOWROOMZ 웹 디자인시스템 v1.3(셸 · 탭 · 액션 모달 · 빈 상태) · GNB #8

[스코프] GNB #8 쇼룸 관리 — 쇼룸 프로필(공개 정보 · 주소 · 연결코드) + 쇼룸 현황 2탭. 계정 · 사업자 · 정산 계좌는 GNB #9 기본정보 관리(ui-studio-06) 소관.
[설계 원칙 — 공개/비공개 분리] 쇼룸(#8) = 소비자에게 공개 / 계정(#9) = 비공개. 구버전 목업 studio-profile이 프로필 · 활동채널 · 정산계좌를 한 화면에 혼재시킨 구조를 두 메뉴로 분리(wf-studio-05 F1·F3 근거).
[셸 재사용] GNB · 탑바 · 버튼 · 입력 · 배지 · 모달은 ui-studio-04-connections.html 및 디자인시스템 v1.3의 셸 · 액션 모달 규격 그대로. 탭은 디자인시스템 「탭」(밑줄 · 배타적 단일선택).
[에러 문구 사용 범위] 필수 미입력은 버튼 비활성만(S2) · 에러 문구는 중복(S3) · 파일 형식/용량(S4)에만. 오류 필드는 보더 위험색 + 문구 1줄.
[연결코드] 쇼룸별 고정 · 재발급 시 이전 코드 즉시 무효 → 되돌릴 수 없는 액션이므로 확인 모달(S5) 필수. 확정 버튼은 파괴적 액션이라 위험색 사용(주 액션색 인디고 규칙과 별개 · 디자인시스템 btn-danger).
[앱 계정과 분리 · 2026.08 변경] 쇼룸명 · 프로필 이미지를 소비자 앱 계정과 공유하지 않음으로 변경(구버전 목업의 "앱 계정 공유" 규칙 폐기) — 쇼룸은 판매 채널의 간판이고 앱 계정은 개인 소비 계정이라 같은 값을 강제하면 어느 한쪽이 부적절해진다. 동일 인물이 두 이름을 갖게 되는 점은 의도된 결과.
[인스타그램 URL] 소비자 노출용 공개 필드로 이 화면에 둠 — 가입 온보딩의 채널 주소를 기본값으로 가져오되 독립 수정 가능. 기본정보 관리의 활동 채널(비공개 · 계약 이행 확인용)과는 별개 데이터.
[드롭다운 항목 · 확정] 기간 = 최근 7일 / 14일 / 30일 / 60일 / 90일 / 6개월 / 1년(기본값 30일) · 인기 콘텐츠 정렬 = 좋아요 많은 순 / 노출 많은 순(기본값 좋아요 많은 순, 최신순 제외 — 순위표의 목적이 성과 비교라 시간순은 의미가 없음). 시안은 닫힌 상태만 표시 — 펼친 팝오버는 디자인시스템에 컴포넌트가 없어 별도 정의 후 추가.
[스냅샷 높이] 본문이 1024px를 넘는 상태는 디자인시스템 v1.3 「1024 초과」 규격에 따라 .stage를 세로로 늘려 전체를 펼쳐 표시했다 — 실제 화면은 GNB · 탑바 고정 + 본문만 스크롤.
[와이어와 다르게 처리한 것 · 팔로워 탭 → 쇼룸 현황] wf-studio-05 F2의 팔로워 탭을 폐기하고 쇼룸 현황 탭으로 교체(2026.08 결정) — 팔로워 목록은 열람 전용 · 개인정보 미표시 · 개별 연락 불가라 인플루언서가 그 화면에서 할 수 있는 행동이 없었다. 화면의 목적을 쇼룸이라는 공개 채널의 반응 지표로 재정의했다. 와이어의 [집계 대기] 등 기획 태그는 UI에서 제거(원칙④).
[지표 정의 · 확정] ⓪ 팔로워 카드 3번째 지표는 직전 동일 기간 대비 증감률 — 절대 수치만으로는 좋은지 나쁜지 판단할 수 없어 비교 기준을 넣었다(게시물 총 개수는 콘텐츠 자산이라 게시물(#5) 소관으로 제외). ① 순방문 = 방문 횟수(같은 소비자 재방문은 30분 세션 기준 1회) ② 방문자 수 = 중복 제거한 사람 수, 팔로우 전환율 = 기간 내 신규 팔로워 ÷ 방문자 수(횟수가 아니라 사람 기준) ③ 인스타그램 링크 클릭 지표는 제외(쇼룸 밖으로 나가는 행동이라 쇼룸 도달 지표와 성격이 다름) · 언팔로우 수 미노출(누가 언팔했는지는 어떤 형태로도 표시하지 않음) ④ 콘텐츠 성과는 인기 콘텐츠 TOP 5(노출 · 좋아요)만 — 판매 · 정산 수치는 판매 현황(#6)과 정산 관리(#7)로 경계를 그었다.
[팔로워 정보 · 2026.08 추가] 게시물 반응 표 · 최근 팔로워 목록을 폐기하고 팔로워 구성(연령대 · 성별) · 팔로워 행동 · 지역 분포 · 인기 콘텐츠 TOP 5로 교체 — 개별 팔로워를 나열해도 할 수 있는 행동이 없었고, 인플루언서에게 필요한 건 누가 보는지에 대한 집계였다. 개인 단위 정보는 어떤 카드에도 표시하지 않는다.
[수집 가능성 · 확인 필요] ① 연령대 · 성별 = 소셜 로그인(카카오) 동의 항목이라 동의자만 집계 — 동의율이 낮으면 "미확인" 비중이 커진다. 동의 항목 신청 여부 확인 필요. ② 지역 = 별도 수집 항목이 없어 공구 배송지 시 · 도로만 추정 가능 → 구매 이력 없는 팔로워는 빠지므로 표본 편향이 있다. 별도 수집(가입 시 지역 선택) 없이 이대로 갈지 결정 필요. ③ 표본 최소치 — 팔로워가 적을 때 구성 비율이 개인을 특정할 수 있어, 일정 인원 미만이면 비율 비공개 규칙이 필요하다(기준 인원 확정 필요).
[유입 경로 전제] 유입 경로는 쇼룸 링크에 붙는 소스 값(예: ?from=ig)과 앱 딥링크에서 그 값을 보존하는 규칙이 있어야 신뢰할 수 있다 — 규칙이 없으면 대부분이 "직접 유입"으로 뭉친다. 링크 발급 규칙 확정 필요.
[와이어 오류] wf-studio-05 전 프레임의 GNB #6이 "성과 관리"로 표기됨 → 확정 9항목의 "판매 현황"으로 정정 적용.
[확인 필요] ① 프로필 이미지 삭제 동선(기본 이미지로 되돌리기)이 와이어에 없음 — S1에 [삭제] 버튼을 넣었으니 기본 이미지 처리 방식 확정 필요. ② 쇼룸명 변경 시 쇼룸 주소가 따라 바뀌지 않는다는 규칙이라, 쇼룸명과 주소가 장기적으로 불일치하게 됨(예: 쇼룸명만 여러 번 변경) — MVP 의도된 것인지 확인 필요.
