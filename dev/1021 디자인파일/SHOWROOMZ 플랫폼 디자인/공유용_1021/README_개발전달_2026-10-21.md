## 1. 반품 · 교환 비용 규칙 (최종)

브랜드가 반품비 · 교환비를 따로 설정하지 않습니다. **상품의 기본 배송비(편도)에서 자동으로 계산**합니다. 예시 금액은 3,000원입니다.

| 경우 | 발송 | 소비자 부담 |
|---|---|---|
| 반품 · 소비자 귀책(단순 변심 · 주문 실수 · 기타) | 선불 직접 발송 | 무료배송 주문만 최초 배송비를 환불액에서 차감. 유료배송 주문은 차감 없음 |
| 반품 · 일부만 반품 | 선불 | 남은 금액이 무료배송 기준(30,000원) 아래로 떨어질 때만 최초 배송비 차감 |
| 교환 · 소비자 귀책 | 선불 직접 발송 | 재발송 배송비(편도)를 요청할 때 결제. 제주·도서산간은 추가 |
| 브랜드 귀책(불량 · 오배송) | 착불 | 없음 |

### 귀책 변경 정산 (기-93)

| 경우 | 처리 |
|---|---|
| 착불 신청 → 검수에서 사유 번복 · 반려 | 브랜드가 낸 착불 운임(기본 배송비 정액)을 소비자가 부담. 반품: 환불액에서 차감 / 반품 전체 반려: 환불액이 없으므로 재발송 배송비와 합쳐 결제 / 교환: 재발송 배송비 결제에 더함 |
| 선불 신청 → 검수에서 브랜드 귀책 | 선불 운임(기본 배송비 정액) + 차감했던 최초 배송비를 환불에 더해 돌려줌 |
| 환불이 원래 결제 금액을 넘는 경우 | 넘는 금액은 **운영자가 계좌로 별도 송금**. 안내 「원래 결제 금액을 넘는 ○원은 1:1 문의로 계좌를 알려 주시면 송금해 드려요」 + [1:1 문의] |

예시 금액(14,000원 상품, 기본 배송비 3,000원)

| 상태 | 금액 |
|---|---|
| 반품 사유 번복 | 환불 8,000원 (14,000 − 최초 배송비 3,000 − 착불 운임 3,000) |
| 반품 귀책 변경 | 환불 17,000원 = 카드 결제 취소 14,000원 + 계좌 송금 3,000원 |
| 반품 일부 반려 + 착불 | 환불 8,500원 |
| 반품 전체 반려 + 착불 | 결제 6,000원 (재발송 3,000 + 착불 3,000) |
| 교환 사유 번복 · 검수 반려 + 착불 | 결제 6,000원 |
