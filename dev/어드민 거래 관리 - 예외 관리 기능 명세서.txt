

## 40. 어드민 거래 관리 — 예외 관리 — [v0.42 신설]

대상 화면: `ui-admin-06d-exceptions.html` (**rev.1**), 상태 2종(처리 지연 탭 · 배송 예외 탭). GNB **6 거래 관리 › 예외 관리** — 배지 = **처리 지연 + 배송 예외**.

**범위 밖** — 송장 대행 · 직권 취소(§37-5) · 반려 이의 처리(§38-5) · 환불(§39) · 분실 판정·보상(택배사·브랜드).

### 40-0. 성격 — 모니터 화면 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| **탭 2개** | **처리 지연**(기본) · 배송 예외 — 둘 다 **지켜보다 필요할 때만 대행**하는 화면이라 페이지를 나누지 않는다 |
| 기본 진입 | 처리 지연 — **운영자가 개입할 수 있는 유일한 탭** |
| **실행 버튼 없음** | 관리 열은 **`열기`뿐** — 대상에 따라 §37 · §38 상세로 간다. 같은 조치를 두 화면에 두면 **근거를 읽지 않고 누르는 경로**가 생긴다 |
| **독촉 버튼 없음** | 기한 경과 알림은 **시스템 자동** — 이 화면은 **횟수만** 보여준다 |
| 데이터 | **새 데이터를 만들지 않는다** — 주문 · 클레임 · 송장에서 조건에 맞는 것을 모아 보여주는 뷰 |

### 40-1. 처리 지연 — 3종 — `FE`·`BE`

| 유형 | 기한 | 판정 | 대상 |
| --- | --- | --- | --- |
| **발송 기한 경과** | 공구 마감 + **주문 시점 N영업일**(기본 3) | 송장 등록 시각 | 주문 |
| **검수 지연** | 입고 확인 + **2영업일** | 검수 판정 | 클레임 |
| **재발송 지연** | 검수 통과·재발송비 결제 + **2영업일** `[근거 대기]` | 재발송 송장 등록 | 클레임 |

| 항목 | 규칙 |
| --- | --- |
| **취소 요청 미응답** | **오지 않는다** — 1영업일 자동 승인(§37-6) |
| 필터 | 유형 셀렉트(건수 병기) + 검색(주문번호 · 접수번호 · 브랜드명) |
| 요약 건수 | `처리 지연 N건 · 연락 두절 N건` |
| 정렬 | 경과 오래된순 |
| 컬럼 8종 | 대상 · 유형 · 브랜드 · **기한** · **경과** · **자동 알림**(N회) · **다음 단계** · 관리 |
| 경과 | 기한을 넘긴 값만 **경고 글자** |

### 40-2. 자동 알림 · 연락 두절 — `BE`

```
기한 경과 ─▶ 자동 알림 1회 ─▶ 2회 ─▶ 3회 무응답 ─▶ 연락 두절 ─▶ 운영자 대행 가능(§37-5)
```

| 항목 | 규칙 |
| --- | --- |
| 알림 | **시스템 자동** · 간격 **1영업일**(시안 값) · 횟수와 마지막 발송 시각 기록 |
| **연락 두절** | 자동 알림 **3회 무응답** `[근거 대기]` — **경고 배지** |
| **대행 개방** | 연락 두절부터 운영자 대행이 열린다 — **주문**은 §37-5의 **송장 대행 등록 · 직권 취소** |
| 다음 단계 열 | `자동 알림 대기 · N회차 MM.DD` / `연락 두절` + 「송장 대행 · 직권 취소 가능」 |
| 클레임 | 검수 지연의 연락 두절 시 대행 범위는 **미정**(§40-4 A-2) |

### 40-3. 배송 예외 — 4종 · 플랫폼 미개입 — `FE`·`BE`

| 유형 | 기준 | 색 | **처리 주체** |
| --- | --- | --- | --- |
| 집화 확인 필요 | 송장 등록 후 **24시간** 미조회 | 경고 | 브랜드 확인 · 시스템 알림 |
| 추적 정지 | 집화 후 **7일** 무갱신 | **위험** | 소비자·브랜드가 택배사 조회 |
| 반송 중 | 반송 코드 감지 | **위험** | 완료 감지 시 PG 자동 환불(재발송 없음) |
| **회수 송장 미조회** | 소비자 입력 회수 송장 — **같은 기준** | — | 시안 예시 없음 |

| 항목 | 규칙 |
| --- | --- |
| **운영자 조치 없음** | 요약에 「운영자 조치 없음 — 관찰」 |
| **처리 주체 열** | 「누가 풀어야 하는가」 — **운영자가 CS 통화에서 답할 문장** |
| 추적 정지 | 누락 = 택배사가 배송완료 처리 · 분실 = 브랜드 재발송 후 송장 수정. **분실 판정·보상은 택배사와 브랜드 사이의 일** |
| 컬럼 8종 | 주문번호 · 유형 · 브랜드 · 송장 · **기준** · **경과** · **처리 주체** · 관리 |
