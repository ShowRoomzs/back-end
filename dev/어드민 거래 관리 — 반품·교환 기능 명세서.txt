
## 38. 어드민 거래 관리 — 반품·교환 — [v0.42 신설]

대상 화면: `ui-admin-06b-claims.html` (**rev.1**), 상태 7종(목록 3 · 상세 모달 4). GNB **6 거래 관리 › 반품·교환**. 기준 파일은 `ui-partner-11-claims` rev.1(§35) · 소비자 앱 **C10-3 · C10-5**(`[미수령]`) · `ui-admin-06a-orders` rev.4(§37).

**범위 밖** — 회수 · 입고 · 검수 · 재발송(소비자·브랜드) · 환불 집행(§39) · 구매확정 후 하자 반품 개설(§37-5).

### 38-0. 성격 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| **브랜드 큐와 같은 탭 · 같은 건수** | 탭 7개와 건수가 §35와 같다 — CS 통화에서 운영자와 브랜드가 **같은 단계 이름**을 써야 한다 |
| 어드민 전용 열 | **브랜드 · 귀책** 둘(반려 보류 탭은 **재발송비 결제** 추가) |
| **운영자가 실행하는 일은 하나** | 검수 반려에 대한 **소비자 이의를 인용하는 운영자 사유 환불**(§38-5) |
| 하지 않는 일 | 회수 · 입고 · 검수 · 재발송 · **신청 단계 반려**(없다) |
| **기각** | **버튼이 아니다** — 반려가 그대로 유지되므로 **스레드로 답한다** |
| 독촉 | **버튼 없음** — 기한 경과는 시스템 자동 알림 |
| 단위 | 항목 단위 클레임 `CLM-NNNN` · 반품·교환은 탭이 아니라 **유형 열**(색 없음) |

### 38-4. 검수 반려 6항목 · 일부 반려 · 환불 계산 — `FE`·`BE`

**6항목은 브랜드 제출값 = 소비자 앱 C10-5 표시값 = 어드민 표시값** — 같은 값 · 같은 순서다. 세 화면을 대조할 수 있어야 이의를 판정한다.

| # | 항목 | 내용 |
| --- | --- | --- |
| 1 | 반려 사유 | 목록 미확정(예: 사용 흔적 · 재판매 불가 / 정상 제품 · 하자 미확인) |
| 2 | **법적 근거** | 예: 전자상거래법 제17조② 1호 — 선택지 미확정(§38-8 A-5) |
| 3 | **범위** | 전체 반려 / **일부 반려**(N / M개) |
| 4 | **귀책** | 변경 없음 / 변경 — 항목 단위 |
| 5 | 증빙 | 사진 + 설명 |
| 6 | 소비자 메시지 | 소비자에게 그대로 전달 |

```
환불 = 상품 금액
     − 최초 배송비   (무료배송 주문 + 소비자 귀책일 때 3,000원)
     − 재발송비      (일부 반려일 때 3,000원)
```

| 항목 | 규칙 |
| --- | --- |
| **전체 반려** | 재발송비를 **소비자가 따로 결제**(별도 PG 거래) → 결제 후 원래 상품 반송 |
| **일부 반려** | 재발송비를 **통과분 환불에서 차감** — 추가 결제 없음 · 원래 결제 **부분 취소** |
| **귀책은 항목 단위** | 통과분 = 브랜드 · 반려분 = 소비자처럼 한 클레임 안에서 갈린다 |
| 정산 | 통과분 차감 · 반려분 정상 |
| ⚠️ 표기 대조 | 「최초 배송비 차감」은 거래플로우 v1.3 · 법률 확정의 **「최초 배송비 별도 공제 없음」**과 문구가 갈린다(§38-8 A-2) |

### 38-5. 운영자 조치 — 반려 이의 인용 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| 위치 | 반려 보류 상세 레일 **인라인 폼** |
| 사유 * | **반려 이의 인용** / 위해성 리콜 / 기타(직접 입력) — §37-5와 같은 3종 |
| 근거 * | 자유 입력 |
| 환불 금액 | **수정 불가** — 인용하면 귀책이 **브랜드**로 바뀌어 배송비 차감이 없다 |
| 버튼 | **`환불 대기 편입`** — 집행은 §39 |
| **인용의 효과** | 반려가 **반품 승인과 같아진다** — ① 귀책 브랜드로 변경 ② **재발송비 결제 요청 취소** ③ 환불 대기 편입 ④ 상품은 브랜드에 남는다 ⑤ 브랜드·소비자 통지. **셋이 한 번에** 일어나야 한다 |
| 기각 | 「받아들이지 않으면 버튼 없이 스레드로 답합니다 — 반려는 그대로 유지됩니다」 |
| 이의 출처 | 소비자 **1:1 문의** — 원문 · 문의 번호 · 사진 · 접수 시각을 ④블록에 표시 |

### 38-7. 운영자 개설 클레임 — `FE`·`BE`

§37-5 **반품 대신 열기**로 만든 클레임이다. 브랜드 화면(§35)에도 **일반 반품으로** 뜬다.

| 항목 | 규칙 |
| --- | --- |
| 구분되는 값 | **출처(운영자 개설)** · **근거 문의** · **법정 기한** 셋 — 나머지는 일반 반품과 같다 |
| ① 클레임 | 개설자 · 개설 시각 · 근거(1:1 문의 번호 · 하자 내용 · 사진) |
| ③ 법정 기한 | 공급일 + 3개월 / 하자 인지 + 30일 → **이른 날** |
| 회수 송장 | 소비자 입력 대기 · **7일 미입력 시 자동 취소** |
| ④ 정산 | 정산 확정 건이면 「통과 시 **다음 정산에서 차감**(브랜드 수취액 · 리워드)」 |
| **귀책** | **브랜드로 열린다**(착불 · 차감 없음) · 브랜드가 검수에서 **소비자로 바꿀 수 있고**, 그 경우 소비자 이의는 §38-5 경로로 받는다 |
| 구현 | 별도 상태 흐름을 만들지 않는다 — 출처 · 근거 · 기한 필드만 추가 |
