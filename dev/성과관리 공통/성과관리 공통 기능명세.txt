### 47-0. 화면의 질문 — 공구 1개 리포트 — `FE`

| 항목 | 규칙 |
| --- | --- |
| 답하는 질문 | 파트너 「이 공구에서 얼마 받나 · 이 인플루언서와 또 할 것인가」 / 스튜디오 「이 공구로 내가 얼마 벌었나 · 이 브랜드와 또 할 것인가」 |
| 구조 | **목록 = 공구 단위 비교표 · 상세 = 공구 1개 리포트** — 브랜드(인플루언서) 전체 대시보드가 아니다 |
| **종료 공구 전용** | 진행 중 공구는 목록에도 상세에도 없다 — 잠정 수치는 받을 돈으로 오해되고 구매확정 · 차감이 끝나야 지표가 나온다. 진행 중 판매 현황은 **공구 관리** |
| 조회 전용 | 금액을 고치거나 정산을 움직이는 액션이 없다. 발신 액션은 **재협업 제안 1개**(파트너 `[이 인플루언서와 재협업 제안]` · 스튜디오 `[이 브랜드와 재협업 제안]` → 연결·소통) — 정정 요청 · 내려받기 · 기간 저장 없음 |
| **관찰 사실만** | 캡션은 측정값과 정의(분모)까지만 — 원인 · 평가어(「주력 상품」) · 추이 요약을 쓰지 않는다. 인과를 단정하면 잘못된 판단의 근거가 된다 |
| 응답 버튼 없음 | 조정 협의 중이어도 동의 · 제안 · 반대 버튼을 두지 않는다 — **응답은 이슈 스레드에서만**(§42 · §43-3과 같은 원칙) |

| ⚠️ 열람 시점 | 파트너 rev.4 「성과 수치는 주문이 끝나면 확정되므로 **정산 단계와 상관없이 열람**」 + **D2(집계 중 상세 · 예정 표시)**가 있는데, 목록의 집계 중 행은 전부 「—」이고 스튜디오 L1 하단은 「집계 중인 공구는 모든 주문 처리가 끝나면 열람」 — **집계 중 행에서 상세를 여는지** 불명 → §55 B-1 |

### 47-2. 지표 정의 — 공통 — `BE`

| 지표 | 정의 | 비고 |
| --- | --- | --- |
| 쇼룸 방문 | 공구 기간 쇼룸 방문 · **고유 방문(명)** | 퍼널 구간 1 · 유입 경로의 분모 |
| **구매전환율**(파트너 라벨 「전환율」) | **쇼룸 방문 → 구매확정** = 구매확정 ÷ 쇼룸 방문 | 「또 할 것인가」에 답한다 |
| **구매확정률** | **주문 → 구매확정** = 구매확정 ÷ 주문 | 「주문이 얼마나 살아남았나」 — 전환율과 **서로 대신 쓰지 않는다** |
| 재구매율 | 재구매 소비자 ÷ 구매 소비자 | ⚠️ **분모 · 판정 범위 불일치** — 파트너 「구매확정 291명」(= 건수) · 이 브랜드 공구 기준 / 스튜디오 「구매 소비자 269명」(중복 제거) · 내 공구 기준 → §55 A-2(X-22) |
| **유입 경로 4종** | **쇼룸 내부 탐색 · 프로필 쇼룸 링크 · 공구 게시물 링크 · 상품 상세 직접 링크** — 쇼룸 안에서 관측되는 **도착 지점** · 4종 합 = 쇼룸 방문(잔여 · 기타 없음) | 딥링크 파라미터 + 앱 내부 리퍼러로만 판정 — **어느 SNS에서 왔는지는 모른다**(화면 고지) · 「스토리 · 릴스 링크」 구분 폐기 · **경로별 주문 배분 없음**(귀속 규칙 미정 — 정의를 UI가 먼저 확정하지 않는다) |
| 공구 게시물 | **쇼룸 내부 지표 · 공구당 1건** — 게시물 조회(회) · 고유 방문 · 상품 상세 이동(조회 대비 %) · 게시물 → 주문(상세 대비 %) · 좋아요 · 공유 | 「주문은 게시물 경유분」 · 게시물이 1건이라 정렬 · 순위 컨트롤 없음 |
| **퍼널 2구간** | 구간 1 = 쇼룸 방문 → 주문(막대 기준 = 방문) / 구간 2 = 주문 → 구매확정(막대 기준 = 주문) · 각 구간 헤더에 기준 명시 · 검산식 「주문 = 구매확정 + 취소 + 반품 + 배송 예외」 · 맨 아래 「방문 대비 최종 구매전환율」 | 5단을 한 축에 그리면 주문 이후가 같은 굵기의 6% 막대가 된다 · 구간 1의 손실은 **숫자로만**(「방문 N명은 주문하지 않았습니다」 — 이탈을 붉게 칠하지 않는다) |
| 성별 · 연령대 | **분포만** — 개별 소비자를 식별할 값 없음 · **구간 인원 5명 미만 = 「기타」 합산**(소규모 공구의 「50대+ 1명」은 특정 개인) · 막대는 최대 구간 기준 스케일 | ⚠️ 표기 단위 불일치 — 파트너 인원(여 16 / 남 1) · 스튜디오 %(0.5 단위 소수) → §55 D-10 |
| 팔로워 구매 비중 | 구매확정(구매) 소비자 중 이 쇼룸을 팔로우한 비율 | 해석 문구 없음(높아도 낮아도 좋고 나쁨이 아니다) |
| 금액 | **확정 거래액**(얼마나 팔렸나) · 정산액 / 내 리워드(얼마 받나) — **정산 관리 산출값을 가져다 쓴다**(같은 숫자를 두 화면에서 따로 계산하면 반드시 어긋난다 · §41 금액의 단일 소스) | 차감 분해는 정산 관리 · 성과 관리는 **해석** |

| 항목 | 규칙 |
| --- | --- |
| 인스타그램 · 메타 요소 | **없다** — 도달 · 저장 · 게시물 마커 · 연동 유도 문구 일절 없음. 콘텐츠 데이터는 쇼룸 내부 지표 · 딥링크 귀속뿐 |
