### 48-3. 원가 · 수익 — 브랜드 전용 — `FE`·`BE`

| 항목 | 규칙 |
| --- | --- |
| 성격 | **선택 입력** · 섹션 상단 「이 정보는 브랜드에게만 보입니다. 입력한 원가는 인플루언서 · 운영자에게 공유되지 않습니다」 — KPI · 목록 · 정산 어디에도 노출하지 않는다(원가는 리워드율 협상 카드) |
| 입력 | 상품별 **개당 원가**(확정 수량 × 개당 원가 = 원가 소계) + **공구 전체 비용** 총액 4종: 부자재비(박스 · 완충재 · 증정품 · 인쇄물) · 배송비(실제 택배 계약 기준 지출액) · 반품 폐기 손실(재판매 불가로 폐기한 상품의 원가) · 기타 |
| 산출 | **총 원가** = 상품 원가 + 부자재 + 배송비 + 반품 폐기 + 기타 · **원가 차감 후 수익** = 정산액 − 총 원가 − 고정 지급비 · **수익률** = 수익 ÷ 확정 거래액 — 플랫폼은 원가를 해석하지 않는다 |
| 이중 차감 방지 | 리워드 · PG · 플랫폼 수수료는 정산액에서 이미 빠졌고 고정 지급비는 자동 반영 — 「여기에 다시 입력하지 마세요」 |
| 미입력(D1-C) | 입력 빈 값 · 소계 「—」 · 계산 카드 자리에 「개당 원가를 입력하면 수익이 계산됩니다」 · `[저장]` 비활성 |
| 입력 완료(D1-D) | 세 값 산출 · `[저장]` 활성 · 언제든 고쳐 재계산 |
| 집계 중(D2) | **입력 잠금** — 「집계가 끝나면 원가를 입력할 수 있습니다」(확정 수량이 바뀌면 소계도 달라진다) · 세 값 「정산 후 확정」 |
| 조정 협의(D3) | 총 원가는 값 · 수익 · 수익률은 「협의 중 · 원래 N원(%)」 |
| 반품·교환 배송비 | 불량 · 오배송의 회수 · 재발송 비용은 정산 대상이 아니라 **여기 배송비에서** 처리한다(§43-4) |
| 데이터 | 브랜드 × 공구 원가 레코드 `[신규제안]` — 도메인모델 미정의(§55 C-7) |
